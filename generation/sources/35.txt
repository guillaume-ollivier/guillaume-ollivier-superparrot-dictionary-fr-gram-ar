# Le comparatif : _ʾafʿal min_

**1** Le comparatif se forme sur le schème *أَفْعَل*, **invariable**, suivi de *مِنْ* (que) :

| adjectif | comparatif |
| --- | --- |
| *كَبِير* (grand) | *أَكْبَرُ* (plus grand) |
| *صَغِير* (petit) | *أَصْغَرُ* |
| *جَمِيل* (beau) | *أَجْمَلُ* |
| *قَرِيب* (proche) | *أَقْرَبُ* |
| *سَهْل* (facile) | *أَسْهَلُ* |

> *القَاهِرَةُ أَكْبَرُ مِنْ بَيْرُوتَ.*
> _al-qāhiratu ʾakbaru min bayrūta._
> Le Caire est plus grand que Beyrouth.

**2** *أَفْعَل* ne change ni en genre ni en nombre : *هِيَ أَكْبَرُ مِنِّي* (elle est plus âgée que moi).

**3** Adjectifs à consonnes redoublées : *جَدِيد* → *أَجَدُّ* ; mais on dit plutôt *أَحْدَثُ* (plus récent).

**4** Comparatifs irréguliers : *خَيْر* → *خَيْرٌ مِنْ* (meilleur), *شَرّ* → *شَرٌّ مِنْ* (pire).

# Le superlatif

**1** Le superlatif est le comparatif **en annexion** :
- avec un nom **indéfini singulier** : *أَكْبَرُ مَدِينَةٍ* (la plus grande ville) ;
- avec un nom **défini pluriel** : *أَكْبَرُ المُدُنِ* (la plus grande des villes).

> *القَاهِرَةُ أَكْبَرُ مَدِينَةٍ عَرَبِيَّةٍ.*
> _al-qāhiratu ʾakbaru madīnatin ʿarabiyyatin._
> Le Caire est la plus grande ville arabe.

**2** Avec un pronom suffixe : *أَكْبَرُهُمْ* (le plus grand d'entre eux).

**3** *أَفْعَل* reste invariable dans ces tournures : *هِيَ أَذْكَى طَالِبَةٍ* (c'est l'étudiante la plus intelligente).

# Comparer les autres adjectifs

**1** Les adjectifs qui ne peuvent pas prendre le schème *أَفْعَل* (participes, couleurs, _nisba_, mots longs) se comparent avec *أَكْثَرُ* (plus) ou *أَقَلُّ* (moins) + **nom verbal à l'accusatif** (_tamyīz_) (§38.2) :

> *هٰذَا الطَّرِيقُ أَكْثَرُ ازْدِحَامًا.*
> _hāḏā ṭ-ṭarīqu ʾakṯaru zdiḥāman._
> Cette route est plus encombrée. (litt. plus en encombrement)

> *هِيَ أَكْثَرُ نَشَاطًا مِنْ أَخِيهَا.*
> _hiya ʾakṯaru našāṭan min ʾaḫīhā._
> Elle est plus active que son frère.

**2** La même tournure sert pour les couleurs : *أَشَدُّ حُمْرَةً* (plus rouge).

**3** *أَكْثَرُ* seul = « plus, davantage » : *أُحِبُّهُ أَكْثَرَ* (je l'aime davantage).
=== EXO

# Le féminin _fuʿlā_ : _al-kubrā_

**1** Quand le superlatif est employé comme **adjectif défini** (après le nom, avec l'article), il s'accorde — féminin en *فُعْلَى* :

| masculin | féminin |
| --- | --- |
| *الأَكْبَرُ* | *الكُبْرَى* (la plus grande) |
| *الأَصْغَرُ* | *الصُّغْرَى* |
| *الأَوَّلُ* | *الأُولَى* |
| *الأَعْلَى* | *العُلْيَا* |

> *الحَرْبُ العَالَمِيَّةُ الأُولَى*
> _al-ḥarbu l-ʿālamiyyatu l-ʾūlā_
> la Première Guerre mondiale

> *المَسْجِدُ الأَكْبَرُ*
> _al-masǧidu l-ʾakbaru_
> la Grande Mosquée

**2** Usages figés : *أَخِي الأَكْبَرُ* (mon frère aîné), *أُخْتِي الصُّغْرَى* (ma petite sœur, la cadette), *الشَّرْقُ الأَوْسَطُ* (le Moyen-Orient).

# L'exclamation : _mā ʾafʿala_

**1** L'admiration « comme… ! » se dit *مَا* + *أَفْعَلَ* (en _-a_) + nom à l'**accusatif** :

> *مَا أَجْمَلَ السَّمَاءَ!*
> _mā ʾaǧmala s-samāʾa!_
> Que le ciel est beau !

> *مَا أَطْيَبَ هٰذَا الطَّعَامَ!*
> _mā ʾaṭyaba hāḏā ṭ-ṭaʿāma!_
> Comme ce plat est délicieux !

**2** Avec un pronom : *مَا أَجْمَلَهَا!* (qu'elle est belle !).

**3** Plus familier : *يَا لَـ* + nom : *يَا لَهُ مِنْ يَوْمٍ!* (quelle journée !).
