# Le nom verbal de la forme I

**1** Le **nom verbal** (_maṣdar_) désigne l'action elle-même : « l'écriture, le fait d'écrire ». Il sert d'infinitif nominal.

**2** En forme I, il n'est **pas prévisible** et s'apprend avec le verbe :

| verbe | nom verbal |
| --- | --- |
| *كَتَبَ* | *كِتَابَة* (écriture) |
| *دَرَسَ* | *دِرَاسَة* (études) |
| *شَرِبَ* | *شُرْب* (boisson, fait de boire) |
| *خَرَجَ* | *خُرُوج* (sortie) |
| *دَخَلَ* | *دُخُول* (entrée) |
| *عَمِلَ* | *عَمَل* (travail) |
| *سَافَرَ* (III) | *سَفَر* / *مُسَافَرَة* (voyage) |

> *الدُّخُولُ مَجَّانِيٌّ.*
> _ad-duḫūlu maǧǧāniyyun._
> L'entrée est gratuite.

**3** Il se construit comme un nom (article, annexion) : *قَبْلَ خُرُوجِي* (avant ma sortie, avant que je sorte).

# Le nom verbal des formes dérivées

**1** Pour les formes II à X, le nom verbal est **régulier** (§29.6) :

| forme | verbe | nom verbal |
| --- | --- | --- |
| II | *دَرَّسَ* | *تَدْرِيس* (enseignement) |
| III | *سَاعَدَ* | *مُسَاعَدَة* (aide) |
| IV | *أَرْسَلَ* | *إِرْسَال* (envoi) |
| V | *تَعَلَّمَ* | *تَعَلُّم* (apprentissage) |
| VI | *تَعَاوَنَ* | *تَعَاوُن* (coopération) |
| VII | *اِنْقَطَعَ* | *اِنْقِطَاع* (coupure) |
| VIII | *اِجْتَمَعَ* | *اِجْتِمَاع* (réunion) |
| X | *اِسْتَعْمَلَ* | *اِسْتِعْمَال* (usage) |

**2** Le nom verbal de la forme IV commence par *إِ* (avec _hamza_), celui des formes VII, VIII et X par *اِ* (sans _hamza_).

> *عِنْدِي اجْتِمَاعٌ فِي العَاشِرَةِ.*
> _ʿindī jtimāʿun fī l-ʿāširati._
> J'ai une réunion à dix heures.

# Le participe actif

**1** Le participe actif (_ism al-fāʿil_) désigne **celui qui fait** l'action ; il sert de nom et d'adjectif.
- Forme I : schème *فَاعِل* : *كَاتِب* (écrivant, écrivain), *سَاكِن* (habitant).
- Formes dérivées : préfixe *مُـ* + radical de l'inaccompli en _i_ : *مُدَرِّس* (II, professeur), *مُسَاعِد* (III, assistant), *مُسْتَعْمِل* (X, utilisateur).

**2** Il exprime souvent un **état présent** ou un futur proche, là où le français met un verbe :

> *أَنَا ذَاهِبٌ إِلَى السُّوقِ.*
> _ʾanā ḏāhibun ʾilā s-sūqi._
> Je vais au marché. (je suis en train d'y aller)

> *هَلْ أَنْتَ فَاهِمٌ؟*
> _hal ʾanta fāhimun?_
> Tu as compris ?

**3** Il s'accorde comme un adjectif : *ذَاهِبَة*, *ذَاهِبُونَ*.

# Le participe passif

**1** Le participe passif (_ism al-mafʿūl_) désigne **ce qui subit** l'action.
- Forme I : schème *مَفْعُول* : *مَكْتُوب* (écrit), *مَعْرُوف* (connu), *مَشْغُول* (occupé).
- Formes dérivées : *مُـ* + radical en **_a_** : *مُرْسَل* (envoyé, IV), *مُسْتَعْمَل* (utilisé, d'occasion, X).

**2** Sans voyelles, *مستعمل* vaut « utilisateur » (_mustaʿmil_) ou « utilisé » (_mustaʿmal_).

> *البَابُ مَفْتُوحٌ.*
> _al-bābu maftūḥun._
> La porte est ouverte.

> *سَيَّارَةٌ مُسْتَعْمَلَةٌ*
> _sayyāratun mustaʿmalatun_
> une voiture d'occasion

# Noms de lieu et d'instrument

**1** Le **nom de lieu** (_ism al-makān_) se forme sur *مَفْعَل* / *مَفْعِل* / *مَفْعَلَة* :

| racine | lieu |
| --- | --- |
| _ك ت ب_ | *مَكْتَب* (bureau), *مَكْتَبَة* (bibliothèque) |
| _ج ل س_ | *مَجْلِس* (conseil, salon) |
| _ط ع م_ | *مَطْعَم* (restaurant) |
| _س ج د_ | *مَسْجِد* (mosquée, lieu de prosternation) |

**2** Le **nom d'instrument** (_ism al-ʾāla_) se forme sur *مِفْعَال*, *مِفْعَل* ou *مِفْعَلَة* :

| racine | instrument |
| --- | --- |
| _ف ت ح_ | *مِفْتَاح* (clé) |
| _ن ش ر_ | *مِنْشَار* (scie) |
| _م س ح_ | *مِمْسَحَة* (serpillière) |
| _ك ن س_ | *مِكْنَسَة* (balai) |

> *أَيْنَ المِفْتَاحُ؟ — فِي المَطْبَخِ.*
> _ʾayna l-miftāḥu? — fī l-maṭbaḫi._
> Où est la clé ? — Dans la cuisine.
