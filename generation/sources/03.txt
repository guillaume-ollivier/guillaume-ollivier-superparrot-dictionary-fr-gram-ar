# L'article _al-_ : défini et indéfini

**1** L'arabe a **un seul article**, défini : _الـ_ (_al-_), invariable, soudé au nom. Il vaut « le, la, les ».

**2** Il n'y a **pas d'article indéfini** : le nom sans article est indéfini, et porte le _tanwīn_ (§2.3).

| indéfini | défini |
| --- | --- |
| *كِتَابٌ* _kitābun_ (un livre) | *الكِتَابُ* _al-kitābu_ (le livre) |
| *بِنْتٌ* _bintun_ (une fille) | *البِنْتُ* _al-bintu_ (la fille) |

**3** Un nom n'a jamais à la fois l'article et le _tanwīn_.

> *الوَلَدُ فِي البَيْتِ.*
> _al-waladu fī l-bayti._
> Le garçon est dans la maison.

**4** On l'écrit toujours _ال_, collé au mot : on tape *الكتاب*.

# Les lettres solaires

**1** Devant certaines consonnes, le _l_ de l'article **ne se prononce pas** : il s'assimile à la consonne, qui se double (_šadda_). On les appelle **lettres solaires**, d'après *الشَّمْس* _aš-šams_ (le soleil).

**2** Ce sont les consonnes prononcées avec le bout de la langue : _ت ث د ذ ر ز س ش ص ض ط ظ ل ن_.

| écrit | prononcé |
| --- | --- |
| *[ar] الشَّمْس /aʃʃams/* | _aš-šams_ (le soleil) |
| *[ar] الرَّجُل /arrad͡ʒul/* | _ar-raǧul_ (l'homme) |
| *[ar] النُّور /annuːr/* | _an-nūr_ (la lumière) |
| *[ar] الدَّرْس /addars/* | _ad-dars_ (la leçon) |

**3** L'écriture ne change pas : le _ل_ reste écrit. On tape toujours *الشمس*.

> *الشَّمْسُ جَمِيلَةٌ.*
> _aš-šamsu ǧamīlatun._
> Le soleil est beau.

# Les lettres lunaires et la _hamzat al-waṣl_

**1** Devant les autres consonnes, le _l_ se prononce : ce sont les **lettres lunaires**, d'après *القَمَر* _al-qamar_ (la lune) : _ا ب ج ح خ ع غ ف ق ك م ه و ي_.

| écrit | prononcé |
| --- | --- |
| *[ar] القَمَر /alqamar/* | _al-qamar_ (la lune) |
| *[ar] البَيْت /albajt/* | _al-bayt_ (la maison) |
| *[ar] الكِتَاب /alkitaːb/* | _al-kitāb_ (le livre) |

**2** Le _a_ de l'article est **instable** (_hamzat al-waṣl_) : il disparaît quand un mot le précède. *فِي البَيْتِ* se dit _fī l-bayti_, *وَالقَمَرُ* _wa-l-qamaru_. Le signe *ٱ* (_waṣla_) le note parfois dans les textes vocalisés.

> *الشَّمْسُ وَالقَمَرُ.*
> _aš-šamsu wa-l-qamaru._
> Le soleil et la lune.

# Lire un mot nouveau : méthode

**1** Repérez les **points** pour identifier chaque lettre, puis les **lettres non liantes** (_ا د ذ ر ز و_) qui découpent le mot.

**2** Cherchez l'**article** _ال_ en tête : il est suivi d'une lettre solaire ou lunaire.

**3** Repérez les **voyelles longues** _ا و ي_ ; entre elles, le texte non vocalisé laisse deviner les brèves.

**4** Une _ة_ finale annonce presque toujours un **féminin** (_-a_).

> *السَّيَّارَةُ الجَدِيدَةُ أَمَامَ المَدْرَسَةِ.*
> _as-sayyāratu l-ǧadīdatu ʾamāma l-madrasati._
> La voiture neuve est devant l'école.

**5** Lire sans voyelles s'apprend avec le vocabulaire : on reconnaît le mot, puis on sait comment le vocaliser.
