# La forme du subjonctif

**1** Le subjonctif (_al-manṣūb_) se forme sur l'inaccompli :
- la voyelle finale _-u_ devient _-a_ : *يَكْتُبُ* → *يَكْتُبَ* ;
- les formes à _n_ perdent leur _n_ : *يَكْتُبُونَ* → *يَكْتُبُوا* (alif muet), *تَكْتُبِينَ* → *تَكْتُبِي*, *يَكْتُبَانِ* → *يَكْتُبَا*.

**2** Les formes en *ـنَ* du féminin pluriel (*يَكْتُبْنَ*) ne changent jamais.

| indicatif | subjonctif |
| --- | --- |
| *أَكْتُبُ* | *أَكْتُبَ* |
| *تَكْتُبِينَ* | *تَكْتُبِي* |
| *يَكْتُبُونَ* | *يَكْتُبُوا* |
| *يَكْتُبْنَ* | *يَكْتُبْنَ* |

**3** Il apparaît après *أَنْ* (que), *لَنْ* (§23.2), *لِـ* / *كَيْ* (pour que) et *حَتَّى* (jusqu'à ce que).

# _ʾAn_ + subjonctif après un verbe

**1** Pour dire « vouloir faire », « pouvoir faire », l'arabe n'a pas d'infinitif : il emploie *أَنْ* + subjonctif, conjugué à la personne voulue :

> *أُرِيدُ أَنْ أَذْهَبَ.*
> _ʾurīdu ʾan ʾaḏhaba._
> Je veux partir. (litt. je veux que je parte)

**2** Tournures fréquentes :

| tournure | sens |
| --- | --- |
| *أُرِيدُ أَنْ…* | je veux… |
| *أُحِبُّ أَنْ…* | j'aime… |
| *أَسْتَطِيعُ أَنْ…* | je peux… |
| *يَجِبُ أَنْ…* | il faut que… |
| *يُمْكِنُ أَنْ…* | il est possible de… |

> *يَجِبُ أَنْ تَدْرُسُوا.*
> _yaǧibu ʾan tadrusū._
> Vous devez étudier.

**3** Le sujet peut différer : *أُرِيدُ أَنْ تَذْهَبَ* (je veux que tu partes).

# But et limite : _li-_, _kay_, _ḥattā_

**1** « Pour (que) » : *لِـ*, *كَيْ* ou *لِكَيْ* + subjonctif :

> *جِئْتُ لِأَدْرُسَ العَرَبِيَّةَ.*
> _ǧiʾtu li-ʾadrusa l-ʿarabiyyata._
> Je suis venu pour étudier l'arabe.

**2** « Pour ne pas » : *لِئَلَّا* ou *لِكَيْ لَا* : *أَسْرَعْتُ لِكَيْ لَا أَتَأَخَّرَ* (je me suis dépêché pour ne pas être en retard).

**3** *حَتَّى* + subjonctif = « jusqu'à ce que, afin que » :

> *اِنْتَظِرْ حَتَّى يَصِلَ القِطَارُ.*
> _intaẓir ḥattā yaṣila l-qiṭāru._
> Attends que le train arrive.

**4** *حَتَّى* + nom = « jusqu'à » : *حَتَّى المَسَاءِ* (jusqu'au soir).

# _ʾAn_ + accompli, et le nom verbal

**1** *أَنْ* peut aussi précéder un **accompli** pour un fait passé : *بَعْدَ أَنْ خَرَجَ* (après qu'il est sorti), *قَبْلَ أَنْ يَخْرُجَ* (avant qu'il sorte — subjonctif, car non réalisé).

**2** *أَنْ* + verbe équivaut souvent à un **nom verbal** (_maṣdar_) (§32.1), plus fréquent dans la presse :

| avec *أَنْ* | avec le nom verbal |
| --- | --- |
| *أُرِيدُ أَنْ أُسَافِرَ* | *أُرِيدُ السَّفَرَ* |
| *قَبْلَ أَنْ يَخْرُجَ* | *قَبْلَ خُرُوجِهِ* |

> *أَكَلْنَا قَبْلَ أَنْ نَخْرُجَ.*
> _ʾakalnā qabla ʾan naḫruǧa._
> Nous avons mangé avant de sortir.

**3** Rappel : *أَنْ* + verbe, *أَنَّ* + nom ou pronom (§22.2).
