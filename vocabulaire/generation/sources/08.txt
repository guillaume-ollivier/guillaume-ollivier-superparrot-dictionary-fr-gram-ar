# Le principe du pluriel brisé

**1** La majorité des noms arabes forment leur pluriel en **modifiant l'intérieur du mot** : les consonnes de la racine restent, les voyelles changent. C'est le **pluriel brisé** (_ǧamʿ at-taksīr_).

| singulier | pluriel |
| --- | --- |
| *كِتَابٌ* _kitābun_ | *كُتُبٌ* _kutubun_ (livres) |
| *وَلَدٌ* _waladun_ | *أَوْلَادٌ* _ʾawlādun_ (enfants) |
| *رَجُلٌ* _raǧulun_ | *رِجَالٌ* _riǧālun_ (hommes) |
| *بَيْتٌ* _baytun_ | *بُيُوتٌ* _buyūtun_ (maisons) |

**2** Les consonnes _ك ت ب_ de _kitāb_ se retrouvent dans _kutub_ : c'est la **racine** (§27.1).

> *فِي المَكْتَبَةِ كُتُبٌ كَثِيرَةٌ.*
> _fī l-maktabati kutubun kaṯīratun._
> Dans la bibliothèque, il y a beaucoup de livres.

**3** Le pluriel brisé n'est pas prévisible à 100 % : il s'apprend avec chaque mot. Dans ce cours, le vocabulaire le donne après _ج_ (pour *جَمْع* « pluriel »).

# Les schèmes de pluriel les plus fréquents (1)

**1** Les pluriels brisés suivent des **moules** (schèmes). On les note avec les consonnes conventionnelles _ف ع ل_ (_f ʿ l_) :

| schème | exemples |
| --- | --- |
| *أَفْعَال* _ʾafʿāl_ | *قَلَمٌ* → *أَقْلَامٌ* ; *اِسْمٌ* → *أَسْمَاءٌ* ; *بَابٌ* → *أَبْوَابٌ* |
| *فُعُول* _fuʿūl_ | *دَرْسٌ* → *دُرُوسٌ* ; *قَلْبٌ* → *قُلُوبٌ* ; *بَيْتٌ* → *بُيُوتٌ* |
| *فِعَال* _fiʿāl_ | *رَجُلٌ* → *رِجَالٌ* ; *كَلْبٌ* → *كِلَابٌ* ; *جَبَلٌ* → *جِبَالٌ* |
| *فُعُل* _fuʿul_ | *كِتَابٌ* → *كُتُبٌ* ; *مَدِينَةٌ* → *مُدُنٌ* |

**2** Ces schèmes prennent les terminaisons normales (_tanwīn_ quand ils sont indéfinis).

> *فِي لُبْنَانَ جِبَالٌ عَالِيَةٌ.*
> _fī lubnāna ǧibālun ʿāliyatun._
> Au Liban, il y a de hautes montagnes.

# Les schèmes de pluriel les plus fréquents (2)

**1** Pour les personnes :

| schème | exemples |
| --- | --- |
| *فُعَلَاء* _fuʿalāʾ_ | *وَزِيرٌ* → *وُزَرَاءُ* ; *رَئِيسٌ* → *رُؤَسَاءُ* |
| *أَفْعِلَاء* _ʾafʿilāʾ_ | *صَدِيقٌ* → *أَصْدِقَاءُ* ; *طَبِيبٌ* → *أَطِبَّاءُ* |
| *فُعَّال* _fuʿʿāl_ | *طَالِبٌ* → *طُلَّابٌ* ; *كَاتِبٌ* → *كُتَّابٌ* |

**2** Pour les mots à quatre consonnes ou commençant par _م_ :

| schème | exemples |
| --- | --- |
| *مَفَاعِل* _mafāʿil_ | *مَدْرَسَةٌ* → *مَدَارِسُ* ; *مَكْتَبٌ* → *مَكَاتِبُ* ; *مَسْجِدٌ* → *مَسَاجِدُ* |
| *فَوَاعِل* _fawāʿil_ | *شَارِعٌ* → *شَوَارِعُ* |
| *مَفَاعِيل* _mafāʿīl_ | *مِفْتَاحٌ* → *مَفَاتِيحُ* (clés) |

**3** Les schèmes _fuʿalāʾ_, _ʾafʿilāʾ_, _mafāʿil_, _fawāʿil_ et _mafāʿīl_ ne prennent **pas** de _tanwīn_ (diptotes) (§33.2) : *مَدَارِسُ*, jamais *مَدَارِسٌ*. _Fuʿʿāl_ le prend : *طُلَّابٌ*.

> *أَصْدِقَائِي طُلَّابٌ.*
> _ʾaṣdiqāʾī ṭullābun._
> Mes amis sont étudiants.

# Accorder avec un pluriel brisé

**1** La règle de l'accord des pluriels (§7.4) vaut aussi pour les pluriels brisés :

| pluriel | accord |
| --- | --- |
| non humain : *كُتُبٌ*, *بُيُوتٌ* | féminin singulier : *كُتُبٌ جَدِيدَةٌ* |
| humain : *رِجَالٌ*, *طُلَّابٌ* | pluriel : *طُلَّابٌ جُدُدٌ*, *رِجَالٌ كِبَارٌ* |

**2** Les adjectifs ont souvent eux aussi un pluriel brisé : *كَبِيرٌ* → *كِبَارٌ*, *صَغِيرٌ* → *صِغَارٌ*, *جَدِيدٌ* → *جُدُدٌ*, *طَوِيلٌ* → *طِوَالٌ*.

> *الطُّلَّابُ الجُدُدُ فِي الصَّفِّ.*
> _aṭ-ṭullābu l-ǧududu fī ṣ-ṣaffi._
> Les nouveaux étudiants sont en classe.

**3** Un pluriel humain féminin s'accorde au féminin pluriel : *البَنَاتُ صَغِيرَاتٌ*.
