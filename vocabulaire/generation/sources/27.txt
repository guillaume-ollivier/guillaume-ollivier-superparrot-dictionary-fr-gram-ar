# La racine

**1** La plupart des mots arabes se ramènent à une **racine** de trois consonnes, porteuse d'un sens général. Les voyelles et les lettres ajoutées précisent ce sens.

**2** La racine _ك ت ب_ (k-t-b) : l'idée d'écrire.

| mot | sens |
| --- | --- |
| *كَتَبَ* | il a écrit |
| *كِتَاب* | livre |
| *كَاتِب* | écrivain |
| *مَكْتَب* | bureau |
| *مَكْتَبَة* | bibliothèque |
| *مَكْتُوب* | écrit, lettre |

**3** La racine _د ر س_ (d-r-s) : l'idée d'étudier : *دَرَسَ* (il a étudié), *دَرْس* (leçon), *مَدْرَسَة* (école), *مُدَرِّس* (professeur), *دِرَاسَة* (études).

> *المُدَرِّسُ فِي المَدْرَسَةِ يَشْرَحُ الدَّرْسَ.*
> _al-mudarrisu fī l-madrasati yašraḥu d-darsa._
> Le professeur, à l'école, explique la leçon.

**4** Connaître les racines permet de **deviner** le sens de mots nouveaux.

wording: Donnez la racine (trois lettres collées) | اكتب الجذر
mode: transfo
مكتبة => كتب
مدرسة => درس
كاتب => كتب
مدرس => درس
مكتوب => كتب
دراسة => درس

# Les schèmes nominaux

**1** On représente un schème avec les consonnes _ف ع ل_. Chaque schème a une valeur typique :

| schème | valeur | exemples |
| --- | --- | --- |
| *فَاعِل* _fāʿil_ | celui qui fait | *كَاتِب* (écrivain), *لَاعِب* (joueur) |
| *مَفْعُول* _mafʿūl_ | ce qui est fait | *مَكْتُوب* (écrit), *مَعْرُوف* (connu) |
| *مَفْعَل* / *مَفْعَلَة* _mafʿal(a)_ | lieu | *مَلْعَب* (stade), *مَدْرَسَة* (école) |
| *فِعَالَة* _fiʿāla_ | métier, activité | *كِتَابَة* (écriture), *تِجَارَة* (commerce) |
| *فَعَّال* _faʿʿāl_ | métier, intensif | *خَبَّاز* (boulanger), *نَجَّار* (menuisier) |

> *اللَّاعِبُ فِي المَلْعَبِ.*
> _al-lāʿibu fī l-malʿabi._
> Le joueur est au stade.

# Chercher un mot dans le dictionnaire

**1** Les dictionnaires classiques sont rangés **par racine** : pour trouver *مَكْتَبَة*, on cherche _ك ت ب_.

**2** Il faut donc retirer les lettres **ajoutées** (préfixes, suffixes, voyelles longues de schème). Elles sont toutes dans le mot mnémotechnique *سَأَلْتُمُونِيهَا* : _س أ ل ت م و ن ي ه ا_.

| mot | lettres ajoutées | racine |
| --- | --- | --- |
| *اِسْتِقْبَال* (accueil) | _ا س ت ا_ | _ق ب ل_ |
| *مُسْتَشْفَى* (hôpital) | _م س ت ى_ | _ش ف ي_ |
| *مَطَار* (aéroport) | _م_ (le _ā_ cache le _ي_) | _ط ي ر_ |

**3** Attention aux racines faibles (§30.1, §31.1) : une lettre _و_ ou _ي_ de la racine peut se cacher dans un _ā_.

> *أَبْحَثُ عَنِ الكَلِمَةِ فِي القَامُوسِ.*
> _ʾabḥaṯu ʿani l-kalimati fī l-qāmūsi._
> Je cherche le mot dans le dictionnaire.

title: Trouver la racine | استخراج الجذر

# Racines de quatre consonnes et emprunts

**1** Quelques racines ont **quatre** consonnes : *تَرْجَمَ* (traduire), *زَلْزَلَ* (secouer), *سَيْطَرَ* (dominer). Inaccompli en _yu-_ : *يُتَرْجِمُ*.

> *أُتَرْجِمُ النَّصَّ إِلَى الفَرَنْسِيَّةِ.*
> _ʾutarǧimu n-naṣṣa ʾilā l-faransiyyati._
> Je traduis le texte en français.

**2** Les racines redoublées (deux syllabes identiques) expriment souvent un son ou un mouvement répété : *زَلْزَلَ* → *زِلْزَال* (séisme).

**3** Les **emprunts** n'ont pas de vraie racine : *تِلِفُون* / *هَاتِف* (téléphone), *كُمْبِيُوتَر* / *حَاسُوب* (ordinateur). L'arabe standard propose souvent un mot formé sur une racine arabe (*هَاتِف*, *حَاسُوب*), à côté de l'emprunt de l'usage courant.
=== EXO
title: Emprunts et mots arabes | الدخيل
wording: Donnez le mot formé sur une racine arabe | اكتب الكلمة العربية
mode: transfo
تلفون => هاتف
كمبيوتر => حاسوب
=== EXO
