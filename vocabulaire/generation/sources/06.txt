# Le féminin en _-a_ (_ة_)

**1** Deux genres seulement : masculin et féminin. Le masculin n'a pas de marque ; le féminin se forme le plus souvent en ajoutant **_tāʾ marbūṭa_** _ة_ (§2.5) :

| masculin | féminin |
| --- | --- |
| *طَالِبٌ* _ṭālibun_ (étudiant) | *طَالِبَةٌ* _ṭālibatun_ (étudiante) |
| *كَبِيرٌ* _kabīrun_ (grand) | *كَبِيرَةٌ* _kabīratun_ (grande) |
| *جَدِيدٌ* _ǧadīdun_ (neuf) | *جَدِيدَةٌ* _ǧadīdatun_ (neuve) |

**2** Un nom en _ة_ est féminin, même s'il désigne une chose : *سَيَّارَةٌ* (voiture), *مَدِينَةٌ* (ville), *غُرْفَةٌ* (chambre).

**3** L'adjectif s'accorde en genre avec le nom :

> *الغُرْفَةُ صَغِيرَةٌ.*
> _al-ġurfatu ṣaġīratun._
> La chambre est petite.

# Le féminin des noms de personnes

**1** Les noms de métier et de fonction forment régulièrement leur féminin en _ة_ :

| masculin | féminin |
| --- | --- |
| *مُعَلِّمٌ* _muʿallimun_ (instituteur) | *مُعَلِّمَةٌ* _muʿallimatun_ |
| *طَبِيبٌ* _ṭabībun_ (médecin) | *طَبِيبَةٌ* _ṭabībatun_ |
| *صَدِيقٌ* _ṣadīqun_ (ami) | *صَدِيقَةٌ* _ṣadīqatun_ (amie) |

**2** Les noms de parenté ont souvent deux mots différents :

| masculin | féminin |
| --- | --- |
| *أَبٌ* _ʾabun_ (père) | *أُمٌّ* _ʾummun_ (mère) |
| *أَخٌ* _ʾaḫun_ (frère) | *أُخْتٌ* _ʾuḫtun_ (sœur) |
| *رَجُلٌ* _raǧulun_ (homme) | *اِمْرَأَةٌ* _imraʾatun_ (femme) |
| *وَلَدٌ* _waladun_ (garçon) | *بِنْتٌ* _bintun_ (fille) |

> *أُخْتِي طَبِيبَةٌ.*
> _ʾuḫtī ṭabībatun._
> Ma sœur est médecin.

**3** *اِمْرَأَة* devient *المَرْأَة* _al-marʾa_ avec l'article.

=== NOTE
# Les féminins sans marque

**1** Certains noms sont féminins **sans** _ة_. Il faut les apprendre :

| nom | sens |
| --- | --- |
| *شَمْسٌ* _šamsun_ | soleil |
| *أَرْضٌ* _ʾarḍun_ | terre |
| *نَارٌ* _nārun_ | feu |
| *حَرْبٌ* _ḥarbun_ | guerre |
| *رِيحٌ* _rīḥun_ | vent |
| *نَفْسٌ* _nafsun_ | âme, soi |

**2** Les **parties du corps qui vont par paires** sont féminines : *يَدٌ* (main), *عَيْنٌ* (œil), *أُذُنٌ* (oreille), *رِجْلٌ* (jambe, pied).

**3** Les noms de **pays et de villes** sont féminins :

> *مِصْرُ كَبِيرَةٌ وَتُونِسُ صَغِيرَةٌ.*
> _miṣru kabīratun wa-tūnisu ṣaġīratun._
> L'Égypte est grande et la Tunisie est petite.

**4** Quelques noms acceptent les deux genres : *سُوقٌ* (marché), *طَرِيقٌ* (chemin).

=== NOTE
# Les féminins en *-āʾ* et *-ā*, et les masculins en _ة_

**1** Deux autres terminaisons marquent le féminin :

| terminaison | exemple |
| --- | --- |
| *ـَاء* _-āʾ_ | *صَحْرَاءُ* _ṣaḥrāʾu_ (désert), *حَمْرَاءُ* _ḥamrāʾu_ (rouge, fém.) (§9.4) |
| *ـَى* _-ā_ | *ذِكْرَى* _ḏikrā_ (souvenir), *كُبْرَى* _kubrā_ (la plus grande) (§35.4) |

> *الصَّحْرَاءُ كَبِيرَةٌ.*
> _aṣ-ṣaḥrāʾu kabīratun._
> Le désert est grand.

**2** Inversement, quelques noms en _ة_ désignent des hommes et restent masculins : *خَلِيفَةٌ* (calife), *رَحَّالَةٌ* (grand voyageur), *عَلَّامَةٌ* (grand savant).

**3** Le genre grammatical se vérifie dans le dictionnaire quand la forme ne suffit pas.
