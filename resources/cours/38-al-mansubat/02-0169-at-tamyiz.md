# Le complément de spécification (_tamyīz_)

**1** Le _tamyīz_ précise **en quoi** : un nom **indéfini à l'accusatif** après une quantité, une mesure ou un comparatif :

| contexte | exemple |
| --- | --- |
| nombre 11–99 (§16.1) | *عِشْرُونَ طَالِبًا* |
| *كَمْ* (§14.4) | *كَمْ كِتَابًا؟* |
| mesure | *اِشْتَرَيْتُ كِيلُو لَحْمًا* (un kilo de viande) |
| comparatif (§35.3) | *أَكْثَرُ نَشَاطًا* |

> *اِزْدَادَ عَدَدُ السُّكَّانِ مِلْيُونًا.*
> _izdāda ʿadadu s-sukkāni milyūnan._
> La population a augmenté d'un million.

**2** Avec « plein de » : *اِمْتَلَأَ الكَأْسُ مَاءً* (le verre s'est rempli d'eau).
