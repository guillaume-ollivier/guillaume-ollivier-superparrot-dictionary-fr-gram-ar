# Impératifs particuliers

**1** Trois verbes très courants perdent leur _ʾ_ initial :

| verbe | impératif |
| --- | --- |
| *أَكَلَ* (manger) | *كُلْ* _kul_ (mange) |
| *أَخَذَ* (prendre) | *خُذْ* _ḫuḏ_ (prends) |
| *أَمَرَ* (ordonner) | *مُرْ* _mur_ |

**2** Les verbes de forme IV (§28.3) ont un alif **avec** _hamza_ : *أَرْسِلْ* _ʾarsil_ (envoie), *أَغْلِقْ* _ʾaġliq_ (ferme).

**3** Les verbes concaves raccourcissent leur voyelle : *قُلْ* _qul_ (dis), *نَمْ* _nam_ (dors) (§30.4).

**4** *تَعَالَ* _taʿāla_ (viens ! — fém. *تَعَالَيْ*, plur. *تَعَالَوْا*) n'a que l'impératif.

> *خُذْ هٰذَا وَكُلْ.*
> _ḫuḏ hāḏā wa-kul._
> Prends ceci et mange.
