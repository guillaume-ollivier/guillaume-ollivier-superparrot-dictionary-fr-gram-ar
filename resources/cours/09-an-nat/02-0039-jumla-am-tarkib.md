# Phrase ou groupe nominal ?

**1** Tout se joue sur l'article de l'adjectif :

| arabe | structure | sens |
| --- | --- | --- |
| *البَيْتُ الكَبِيرُ* | nom défini + adjectif défini | la grande maison (groupe) |
| *البَيْتُ كَبِيرٌ* | nom défini + adjectif indéfini | la maison est grande (phrase) |
| *بَيْتٌ كَبِيرٌ* | nom indéfini + adjectif indéfini | une grande maison (groupe) |

**2** On peut combiner les deux :

> *البَيْتُ الجَدِيدُ كَبِيرٌ.*
> _al-baytu l-ǧadīdu kabīrun._
> La maison neuve est grande.

**3** Quand l'attribut est lui-même défini, on insère le pronom de séparation (_ḍamīr al-faṣl_) : *هَذَا هُوَ الطَّرِيقُ* « c'est le chemin ».
