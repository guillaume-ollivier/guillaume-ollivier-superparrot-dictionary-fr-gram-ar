# Accorder avec un duel

**1** L'adjectif qui qualifie un duel prend lui aussi le duel, avec la même terminaison :

> *البِنْتَانِ جَمِيلَتَانِ.*
> _al-bintāni ǧamīlatāni._
> Les deux filles sont belles.

> *عِنْدِي سَيَّارَتَانِ قَدِيمَتَانِ.*
> _ʿindī sayyāratāni qadīmatāni._
> J'ai deux vieilles voitures.

**2** Le pronom de reprise est *هُمَا* (§5.3), et le verbe a ses formes duelles (§17.4).

**3** Récapitulatif de l'accord :

| nom | accord |
| --- | --- |
| singulier | singulier, même genre |
| duel | duel, même genre |
| pluriel humain | pluriel, même genre |
| pluriel non humain | féminin singulier |
