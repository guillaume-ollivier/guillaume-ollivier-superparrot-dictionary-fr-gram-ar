Chercher un mot dans le dictionnaire

1 Les dictionnaires classiques sont rangés par racine : pour trouver مَكْتَبَة, on cherche ك ت ب.

2 Il faut donc retirer les lettres ajoutées (préfixes, suffixes, voyelles longues de schème). Elles sont toutes dans le mot mnémotechnique سَأَلْتُمُونِيهَا : س أ ل ت م و ن ي ه ا.

mot lettres ajoutées racine
اِسْتِقْبَال (accueil)ا س ت اق ب ل
مُسْتَشْفَى (hôpital)م س ت ىش ف ي
مَطَار (aéroport)م (le ā cache le ي)ط ي ر

3 Attention aux racines faibles (§30.1, §31.1) : une lettre و ou ي de la racine peut se cacher dans un ā.

أَبْحَثُ عَنِ الكَلِمَةِ فِي القَامُوسِ.
ʾabḥaṯu ʿani l-kalimati fī l-qāmūsi.
Je cherche le mot dans le dictionnaire.
