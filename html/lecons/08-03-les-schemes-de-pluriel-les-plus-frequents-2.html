Les schèmes de pluriel les plus fréquents (2)

1 Pour les personnes :

schème exemples
فُعَلَاء fuʿalāʾوَزِيرٌ → وُزَرَاءُ ; رَئِيسٌ → رُؤَسَاءُ
أَفْعِلَاء ʾafʿilāʾصَدِيقٌ → أَصْدِقَاءُ ; طَبِيبٌ → أَطِبَّاءُ
فُعَّال fuʿʿālطَالِبٌ → طُلَّابٌ ; كَاتِبٌ → كُتَّابٌ

2 Pour les mots à quatre consonnes ou commençant par م :

schème exemples
مَفَاعِل mafāʿilمَدْرَسَةٌ → مَدَارِسُ ; مَكْتَبٌ → مَكَاتِبُ ; مَسْجِدٌ → مَسَاجِدُ
فَوَاعِل fawāʿilشَارِعٌ → شَوَارِعُ
مَفَاعِيل mafāʿīlمِفْتَاحٌ → مَفَاتِيحُ (clés)

3 Les schèmes fuʿalāʾ, ʾafʿilāʾ, mafāʿil, fawāʿil et mafāʿīl ne prennent pas de tanwīn (diptotes) (§33.2) : مَدَارِسُ, jamais مَدَارِسٌ. Fuʿʿāl le prend : طُلَّابٌ.

أَصْدِقَائِي طُلَّابٌ.
ʾaṣdiqāʾī ṭullābun.
Mes amis sont étudiants.
