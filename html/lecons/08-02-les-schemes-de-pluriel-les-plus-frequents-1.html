Les schèmes de pluriel les plus fréquents (1)

1 Les pluriels brisés suivent des moules (schèmes). On les note avec les consonnes conventionnelles ف ع ل (f ʿ l) :

schème exemples
أَفْعَال ʾafʿālقَلَمٌ → أَقْلَامٌ ; اِسْمٌ → أَسْمَاءٌ ; بَابٌ → أَبْوَابٌ
فُعُول fuʿūlدَرْسٌ → دُرُوسٌ ; قَلْبٌ → قُلُوبٌ ; بَيْتٌ → بُيُوتٌ
فِعَال fiʿālرَجُلٌ → رِجَالٌ ; كَلْبٌ → كِلَابٌ ; جَبَلٌ → جِبَالٌ
فُعُل fuʿulكِتَابٌ → كُتُبٌ ; مَدِينَةٌ → مُدُنٌ

2 Ces schèmes prennent les terminaisons normales (tanwīn quand ils sont indéfinis).

فِي لُبْنَانَ جِبَالٌ عَالِيَةٌ.
fī lubnāna ǧibālun ʿāliyatun.
Au Liban, il y a de hautes montagnes.
