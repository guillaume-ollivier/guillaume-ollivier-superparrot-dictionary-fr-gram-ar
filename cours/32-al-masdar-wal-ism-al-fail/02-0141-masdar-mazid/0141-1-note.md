# Le nom verbal des formes dérivées

**1** Pour les formes II à X, le nom verbal est **régulier** (§29.6) :

| forme | verbe | nom verbal |
| --- | --- | --- |
| II | *دَرَّسَ* | *تَدْرِيس* (enseignement) |
| III | *سَاعَدَ* | *مُسَاعَدَة* (aide) |
| IV | *أَرْسَلَ* | *إِرْسَال* (envoi) |
| V | *تَعَلَّمَ* | *تَعَلُّم* (apprentissage) |
| VI | *تَعَاوَنَ* | *تَعَاوُن* (coopération) |
| VII | *اِنْقَطَعَ* | *اِنْقِطَاع* (coupure) |
| VIII | *اِجْتَمَعَ* | *اِجْتِمَاع* (réunion) |
| X | *اِسْتَعْمَلَ* | *اِسْتِعْمَال* (usage) |

**2** Le nom verbal de la forme IV commence par *إِ* (avec _hamza_), celui des formes VII, VIII et X par *اِ* (sans _hamza_).

> *عِنْدِي اجْتِمَاعٌ فِي العَاشِرَةِ.*
> _ʿindī jtimāʿun fī l-ʿāširati._
> J'ai une réunion à dix heures.
