# Noms de lieu et d'instrument

**1** Le **nom de lieu** (_ism al-makān_) se forme sur *مَفْعَل* / *مَفْعِل* / *مَفْعَلَة* :

| racine | lieu |
| --- | --- |
| _ك ت ب_ | *مَكْتَب* (bureau), *مَكْتَبَة* (bibliothèque) |
| _ج ل س_ | *مَجْلِس* (conseil, salon) |
| _ط ع م_ | *مَطْعَم* (restaurant) |
| _س ج د_ | *مَسْجِد* (mosquée, lieu de prosternation) |

**2** Le **nom d'instrument** (_ism al-ʾāla_) se forme sur *مِفْعَال*, *مِفْعَل* ou *مِفْعَلَة* :

| racine | instrument |
| --- | --- |
| _ف ت ح_ | *مِفْتَاح* (clé) |
| _ن ش ر_ | *مِنْشَار* (scie) |
| _م س ح_ | *مِمْسَحَة* (serpillière) |
| _ك ن س_ | *مِكْنَسَة* (balai) |

> *أَيْنَ المِفْتَاحُ؟ — فِي المَطْبَخِ.*
> _ʾayna l-miftāḥu? — fī l-maṭbaḫi._
> Où est la clé ? — Dans la cuisine.
