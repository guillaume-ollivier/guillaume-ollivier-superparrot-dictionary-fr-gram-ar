# _ʾAyna_, _matā_, _kayfa_ : où, quand, comment

| mot | sens | exemple |
| --- | --- | --- |
| *أَيْنَ* _ʾayna_ | où | *أَيْنَ المَحَطَّةُ؟* (où est la gare ?) |
| *مِنْ أَيْنَ* | d'où | *مِنْ أَيْنَ أَنْتِ؟* |
| *إِلَى أَيْنَ* | où (direction) | *إِلَى أَيْنَ تَذْهَبُ؟* (où vas-tu ?) |
| *مَتَى* _matā_ | quand | *مَتَى الامْتِحَانُ؟* (quand est l'examen ?) |
| *كَيْفَ* _kayfa_ | comment | *كَيْفَ حَالُكَ؟* |

> *مَتَى تَبْدَأُ الحِصَّةُ؟*
> _matā tabdaʾu l-ḥiṣṣatu?_
> Quand le cours commence-t-il ?

L'interrogatif est **toujours en tête**, sans inversion du sujet.
