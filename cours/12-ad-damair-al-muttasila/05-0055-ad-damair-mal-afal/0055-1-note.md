# Suffixes compléments d'un verbe

**1** Le complément d'objet pronom est le même suffixe, collé au verbe. Seule la 1ʳᵉ personne change : *ـنِي* _-nī_ (me) au lieu de _-ī_.

| verbe | + suffixe | sens |
| --- | --- | --- |
| *يَعْرِفُ* (il connaît) | *يَعْرِفُنِي* _yaʿrifunī_ | il me connaît |
| | *يَعْرِفُكَ* | il te connaît |
| | *يَعْرِفُهَا* | il la connaît |
| | *يَعْرِفُهُمْ* | il les connaît |

**2** Pour un pronom complément **sans** verbe support, on emploie *إِيَّا* + suffixe : *إِيَّاكَ نَعْبُدُ* (c'est toi que nous adorons).

> *أُحِبُّكِ.*
> _ʾuḥibbuki._
> Je t'aime (à une femme).
