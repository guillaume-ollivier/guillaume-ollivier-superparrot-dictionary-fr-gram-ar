# Lire un mot nouveau : méthode

**1** Repérez les **points** pour identifier chaque lettre, puis les **lettres non liantes** (_ا د ذ ر ز و_) qui découpent le mot.

**2** Cherchez l'**article** _ال_ en tête : il est suivi d'une lettre solaire ou lunaire.

**3** Repérez les **voyelles longues** _ا و ي_ ; entre elles, le texte non vocalisé laisse deviner les brèves.

**4** Une _ة_ finale annonce presque toujours un **féminin** (_-a_).

> *السَّيَّارَةُ الجَدِيدَةُ أَمَامَ المَدْرَسَةِ.*
> _as-sayyāratu l-ǧadīdatu ʾamāma l-madrasati._
> La voiture neuve est devant l'école.

**5** Lire sans voyelles s'apprend avec le vocabulaire : on reconnaît le mot, puis on sait comment le vocaliser.
