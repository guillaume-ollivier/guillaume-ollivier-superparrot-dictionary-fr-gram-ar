# Chercher un mot dans le dictionnaire

**1** Les dictionnaires classiques sont rangés **par racine** : pour trouver *مَكْتَبَة*, on cherche _ك ت ب_.

**2** Il faut donc retirer les lettres **ajoutées** (préfixes, suffixes, voyelles longues de schème). Elles sont toutes dans le mot mnémotechnique *سَأَلْتُمُونِيهَا* : _س أ ل ت م و ن ي ه ا_.

| mot | lettres ajoutées | racine |
| --- | --- | --- |
| *اِسْتِقْبَال* (accueil) | _ا س ت ا_ | _ق ب ل_ |
| *مُسْتَشْفَى* (hôpital) | _م س ت ى_ | _ش ف ي_ |
| *مَطَار* (aéroport) | _م_ (le _ā_ cache le _ي_) | _ط ي ر_ |

**3** Attention aux racines faibles (§30.1, §31.1) : une lettre _و_ ou _ي_ de la racine peut se cacher dans un _ā_.

> *أَبْحَثُ عَنِ الكَلِمَةِ فِي القَامُوسِ.*
> _ʾabḥaṯu ʿani l-kalimati fī l-qāmūsi._
> Je cherche le mot dans le dictionnaire.
