# Les schèmes nominaux

**1** On représente un schème avec les consonnes _ف ع ل_. Chaque schème a une valeur typique :

| schème | valeur | exemples |
| --- | --- | --- |
| *فَاعِل* _fāʿil_ | celui qui fait | *كَاتِب* (écrivain), *لَاعِب* (joueur) |
| *مَفْعُول* _mafʿūl_ | ce qui est fait | *مَكْتُوب* (écrit), *مَعْرُوف* (connu) |
| *مَفْعَل* / *مَفْعَلَة* _mafʿal(a)_ | lieu | *مَلْعَب* (stade), *مَدْرَسَة* (école) |
| *فِعَالَة* _fiʿāla_ | métier, activité | *كِتَابَة* (écriture), *تِجَارَة* (commerce) |
| *فَعَّال* _faʿʿāl_ | métier, intensif | *خَبَّاز* (boulanger), *نَجَّار* (menuisier) |

> *اللَّاعِبُ فِي المَلْعَبِ.*
> _al-lāʿibu fī l-malʿabi._
> Le joueur est au stade.
